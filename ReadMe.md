## Descripción

MatchPoint es una aplicación web para consultar y organizar torneos de pádel entre amigos, gestionar participantes, generar enfrentamientos y registrar resultados.

## Entregas

### Primera entrega

Sitio desarrollado con HTML, CSS y JavaScript.

[Ver documentación de la primera entrega](primera-entrega/Readme.md)

### Segunda entrega

Migración a React, Vite, React Router y Sass, con un mock de servicios mediante json-server.

[Ver documentación y pasos de ejecución](segunda-entrega/matchpoint/README.md)
